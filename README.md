# akosuacreates.studio

A lightweight static V1 website for Akosua Creates.

## Routes

- `/` — Home
- `/about/` — About The Artist
- `/portfolio/digital-art/` — Digital Art
- `/portfolio/physical-art/` — Physical Art
- `/poetry/` — Poetry

## Development

```bash
npm run build
npm start
```

The build script writes the static site to `dist/`, which can be deployed to GitHub Pages or another static host.
