# akosuacreates.studio

A lightweight static V1 website for Akosua Creates.

## Routes

- `/` — Home
- `/about/` — About The Artist
- `/portfolio/digital-art/` — Digital Art
- `/portfolio/physical-art/` — Physical Art
- `/poetry/` — Poetry

## Development

Build the static site:

```bash
npm run build
```

Preview the generated site locally:

```bash
npm start
```

The build script writes the static site to `dist/`.

## GitHub Pages deployment

This repository should deploy with **GitHub Actions**, not from `main`/root, `docs`, or a committed `dist` folder:

- Root does not contain a finished `index.html`; it contains source files and build scripts.
- `docs/` is reserved for design references, including the navigation structure image.
- `dist/` is generated by `npm run build` and intentionally ignored by Git.
- GitHub Actions is the simplest correct option because it builds `dist/` on every push to `main` and uploads that generated folder to GitHub Pages.

In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. After the next push to `main`, the `Deploy static site to GitHub Pages` workflow will publish the site.
